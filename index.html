🔒 編集モード

日程の編集・公開にはパスワードが必要です。

⚙ 公開設定

「公開」を押すと、日程と選手・設定が GitHub の data.json に保存され、同じURLを開いた全員に反映されます（反映まで1〜2分）。
トークンの作り方 GitHub → 右上アイコン → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
・Repository access：Only select repositories → schedule のみ
・Permissions → Repository permissions → Contents：Read and write
・Expiration：期限を決める（最長1年）。作成後に表示される文字列をここに貼り付けます。
